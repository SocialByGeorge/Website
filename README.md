# Social By George website

A GitHub Pages-ready website for **Social By George** — social media management for hair, beauty and wellness businesses.

## Live business details already added

- Instagram: **@socialbygeorge**
- Enquiries: **Instagram only**
- Starting price: **from £99/month**
- Brand-led presentation: **no founder photo required**
- Logo: the existing Social By George SBG monogram
- Booking: website buttons open Instagram and copy either `BOOK` or `SOCIAL` so visitors know what to DM

## Publish with GitHub Pages

1. Create a new GitHub repository, for example `social-by-george`.
2. Upload everything inside this folder to the repository root.
3. Commit the files.
4. Open **Settings → Pages** in the repository.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select your main branch and `/ (root)`, then save.
7. GitHub will provide the live site address after deployment.

## Booking link

Until you choose a calendar/booking provider, **Book via Instagram** opens:

`https://www.instagram.com/socialbygeorge/`

The button also copies `BOOK` to the visitor's clipboard. If you later create a Calendly, Cal.com, Square, Fresha or other booking link, replace the Instagram booking CTA with that URL.
