# Social by George — Website

A responsive static website using the Social by George brand palette:
- Jet Black `#0B0B0B`
- Off-White `#F5F5F1`
- Electric Lime `#C6FF5E`
- Charcoal `#2A2A2A`
- Sage Green `#9ACB7A` (optional accent)

## Files
- `index.html` — page content
- `style.css` — layout, palette, responsive styling
- `script.js` — mobile navigation and current year

## Before publishing
1. In `index.html`, replace `YOUR-EMAIL@example.com` with your real business email.
2. Check the Instagram links point to your preferred handle.
3. Replace the sample project graphic with genuine portfolio screenshots when ready.
4. Preview locally, then upload the files to your GitHub Pages repository.

## Publish with GitHub Pages
1. Open your website repository on GitHub.
2. Upload/replace `index.html`, `style.css`, `script.js`, and this README at the repository root.
3. Commit the changes.
4. In **Settings → Pages**, ensure the correct branch and root folder are selected.
5. Visit your published GitHub Pages URL after the deployment finishes.

This is a static site and requires no build step.
