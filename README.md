# Social By George — GitHub Pages Launch Build

## Upload
Upload these files directly to the ROOT of the `SocialByGeorge/Website` repository:

- `index.html`
- `.nojekyll`

Do **not** upload the outer folder itself.

Your repository root should look like:

    index.html
    .nojekyll
    README.md   (optional)

## GitHub Pages settings
GitHub → repository → Settings → Pages

- Source: Deploy from a branch
- Branch: main
- Folder: /(root)

Expected public URL:

https://socialbygeorge.github.io/Website/
